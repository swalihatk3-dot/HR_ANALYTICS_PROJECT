# HR Analytics Project

## Project Overview
This project focuses on analysing employee-related data using PostgreSQL. The main purpose is to identify useful business insights that help the HR department make better decisions.

## Business Problem
The HR department needs a better way to understand employee information, track attendance, compare salaries, and evaluate employee performance.

## Project Objective
- Analyse employee distribution.
- Evaluate salary distribution and expenditure.
- Monitor employee attendance.
- Analyse employee performance.
- Generate useful business insights.

## Tools Used
- PostgreSQL
- pgAdmin
- SQL

## Database Overview
Database Name: `hr_analytics_db`

### Tables
1. Departments
2. Employees
3. Attendance
4. Performance

## Key Business Insights
1. The organisation has 10 employees: 6 female and 4 male.
2. Total salary expenditure is ₹4,15,000.
3. IT and Finance have the highest average salary of ₹52,500.
4. IT and Finance have the highest average performance rating of 4.5 out of 5.
5. Arjun has the highest salary of ₹60,000, while Meera has the lowest salary of ₹28,000.

This project helped analyse employee data using PostgreSQL and generate meaningful business insights. It also improved practical knowledge of SQL and data analysis.
